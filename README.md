# avito-feed

Фид автозагрузки Авито. **С 05.11.2026 все объявления сняты:** пустой файл Авито не принимает (ошибка 306), поэтому в фиде 5 последних объявлений с `DateEnd=2026-11-05`. Не убирать дату, пока автозагрузка включена — иначе они снова выйдут. Направление «Нейросотрудник» закрыто (Новофон не одобрил номер, объявления не дали заявок), прошивки тоже сняты — Артём вернул обычный профиль. История объявлений — в git log, обложки оставлены в covers/ как архив.
